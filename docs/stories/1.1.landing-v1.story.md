# Story 1.1 — Landing v1 (donadaolabs.com)

**Status:** Done
**Epic:** Donadão Labs Public Site
**Owner:** @aiox-master (Orion)
**Created:** 2026-05-07
**Completed:** 2026-05-07

---

## User Story

**As a** founder/operator visiting donadaolabs.com,
**I want** a single landing page that explains what Donadão Labs does, who we ship for, and how to book a diagnostic call,
**so that** I can decide in under 60 seconds whether to engage and book a `cal.com/donadaolabs/diagnostico` slot.

---

## Context

Greenfield project. No prior Next.js scaffold in this branding kit. The static reference at `../03-website/index.html` is the visual baseline (already brand-aligned). All brand assets, voice/tone rules, and `tokens.css` come from `../01-brand-kit/` and `../07-contexto/donadaolabs.md`.

This is a **single-page** marketing site. No backend, no auth, no DB. CTA is an external link to Cal.com.
