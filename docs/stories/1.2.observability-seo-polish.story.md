## User Story

**As a** founder shipping a public marketing site,
**I want** observability (analytics), SEO baseline (sitemap, robots, JSON-LD), branded 404 page, and the source-of-truth `donadaolabs.md` updated,
**so that** the site is discoverable by Google, conversion is measurable, broken paths fail with brand presence, and future Claude Code sessions have accurate context.

## Acceptance Criteria

### AC1 — Source of truth (Story 2.4)
- [ ] `07-contexto/donadaolabs.md` updated:
  - [ ] Case 04 Cali Garage added under "Active Products"
  - [ ] Hero copy reflects current accessible PT version
  - [ ] Voice note refinements (no "Donadão Labs Manifesto" attribution)

### AC2 — Sitemap + robots.txt (Story 2.2)
- [ ] `app/sitemap.ts` returns single-URL sitemap (`donadaolabs.com`)
- [ ] `app/robots.ts` allows all bots, references sitemap URL
- [ ] Both routes return 200 in production

### AC3 — Schema.org Organization JSON-LD (Story 2.3)
- [ ] `<script type="application/ld+json">` in `<head>` with Organization markup
- [ ] Includes: name, url, logo, description, founder, sameAs (LinkedIn, GitHub, Instagram)
- [ ] Validates in [Schema.org validator](https://validator.schema.org/)
- [ ] Validates in [Google Rich Results Test](https://search.google.com/test/rich-results)

### AC4 — Custom 404 page (Story 2.5)
- [ ] `app/not-found.tsx` created
- [ ] Brand-aligned: Inter Tight, charcoal background, accent purple, copy in voice/tone
- [ ] CTA back to home (Voltar pra donadaolabs.com)
- [ ] Mobile responsive

### AC5 — Analytics (Story 2.1)
- [ ] Provider chosen by founder: `vercel | plausible | umami`
- [ ] Component/script added to `app/layout.tsx`
- [ ] Page view tracked
- [ ] Cal.com CTA click tracked (custom event, if provider supports)

### AC6 — HSTS preload submission (Story 2.6)
- [ ] Document the manual submission process for founder
- [ ] Confirm headers ready (`Strict-Transport-Security: max-age=63072000; includeSubDomains; preload`)
- [ ] Founder submits at https://hstspreload.org

### AC7 — Quality gates (Constitution: Quality First)
- [ ] `npm run lint` passes
- [ ] `npm run typecheck` passes
- [ ] `npm run build` completes
- [ ] No regression in `/` page weight (was 14.3 kB / 102 kB First Load)
